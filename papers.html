ENGRAM: Egocentric Neural Grounded Retrieval of Actions and Moments

A wearable memory assistant built on an interaction-triggered reference diary. A 0.24M-parameter HOI-TCN decides when a vision-language model looks, an object-state memory recovers open / close actions the VLM misses (17 → 30 of 69), and answers come only from the text diary. Over a whole morning it beats the VLM shown everything (76% vs. 66%) and invents no events. Evaluated on EPIC-KITCHENS-100, with an Ego4D NLQ run pending. In preparation.
